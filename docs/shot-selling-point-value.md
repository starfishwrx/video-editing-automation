# 选镜首先判断动作有没有卖点信息

门槛是：至少传达一个具体卖点即可，不要求一个镜头覆盖整句所有卖点。没对应的内容保留备注，不作为该镜头淘汰条件。画面清楚、同商品、手在动、高置信度，都不能替代卖点信息。

`shot_value_review`独立看实际帧和原句，先回答“做了什么→看到了什么变化/特点/结果→与哪个原文卖点相关”。它不接收上一轮语义通过或可读性结论，也不接受把“不闷热、不粘腻”换成“柔软、亲肤”。检查项的claim_text必须来自原句；静态侧边、纹理或标称若能呈现本句特点，也可有效，不强求动作。

| 画面内容 | 对应本句时的处理 |
|---|---|
| 普通抚摸、折拢，但没有揭示或强调相关特点 | generic_motion；具体卖点镜头拒选 |
| 一个实际动作或静态视角呈现相关特点 | feature_presentation；至少一项成立即可选 |
| 实际演示并看到相应结果 | direct_demonstration；优先于只有联想的展示 |
| 只支持其中一项 | PARTIAL且selection_eligible=true；未覆盖项只备注 |
| 通用本体/包装展示 | 可用于普通介绍；不能自动升级成性能表达 |

该判断进入候选复核、固定时长求解、排序和实际输出复核。先看最有信息价值的一项，再比较覆盖数量、可读性、速度及重复；不以卖点数量压过更直接的演示。保护实际卖点证据区间原速，原句及音轨不变。`review_output`同样以至少一个被实际支持的卖点为展示镜头门槛，明确返回覆盖范围，不将部分支持说成整句功效已证实。

观察协议v6、输出复核v8使上轮仅有可读性判断的完整选镜/复核产物失效；旧分析描述仍可召回。本次没有替换默认生产或正式交付规则。

卫品42第7句复验：033折拢和036抚摸都没有给“不闷热/不粘腻”增加具体信息，被拒选。旧缓存召回的076显示背面照光后正面透光变化，有明确展示目的，可作薄透相关表达，支持一项即可入选；不把它当作空气透过率、实际温感或不粘腻证明。选择0–2.725397秒，配音和句长不变。真实对照、模型原答、固定音轨验证保存在包外。

这更正上一轮仅因036主体更清楚而宣布卖点选镜改善的结论。[可读性说明](shot-usability.md)仍作为辅助检查，不能单独决定动作是否有效。
