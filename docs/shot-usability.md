# 展示镜头可用性：先看清，再匹配

本页是可读性辅助检查，不能单独判定动作有卖点价值。用户随后明确：至少传达一个具体卖点即可，不要求整句完全匹配。当前优先规则见[卖点信息价值](shot-selling-point-value.md)；下方036的可读性改善不再作为本句卖点有效的结论，它在新门槛下仍因缺少对应信息而被拒选。

同商品、语义相关、高置信度和能放进句长，都不能单独判定镜头有效。普通介绍可用稳定本体/包装展示；具体薄软、舒适等体验，要看到贴切的信息点，不能把收拢整理、手遮挡或未完成动作当成演示结果。体验展示不需要虚构人体实验，也不自动证明透气、不闷热或不粘腻等功效。

## 程序行为

1. `shot_quality_review`先看实际候选帧，不接收口播、旧标签或先前匹配结论，记录主体可读区间、展示/整理、完成形态及限制。稳定拿持、少量手指轻触可以是正常展示，不因没有性能实验而一概拒绝。
2. `purpose_review`再检查口播目标。`shot_usability`取盲观察和目标特征可读区间的交集；语义可以收窄，不能把主体清楚的2秒扩张成只有0.3秒可见的薄边。两份原始观察分别保留，通用画面事实不改成文案推断。
3. 先过滤大面积遮挡、主要整理/准备、未完成的演示、仅联想或不相关的镜头。默认要求可读信息覆盖拟用窗口至少一半，且有至少600ms连续可读段（短于600ms的句子按该句长）；这是预览筛选启发式，不是内容认证。
4. 具体信息可读区间保护为原速。补入上下文必须位于本次真实复核范围内且有可读事实覆盖；不满足则要求重看，不能用新增准备凑长。过滤后按明确支持项、实际画面比较、可读覆盖、自然速度和去重等排序；模型置信度靠后。
5. 至少两个可用候选时，用最终计划源窗重新抽图、匿名比较实际画面。比选失败或全部拒绝时不回退到高置信度旧镜头。单次最多三候选，不自动重扫全库。

`purpose_production.select`和实际输出复核已接入共用判断。观察协议为`purpose-observation-v5-blind-shot-usability`，输出复核为`purpose-output-review-v7-blind-shot-usability`；旧完整选镜/复核结论不能自动复用，旧描述索引仍可作候选召回。

## 单句固定输入入口

```powershell
uv run --frozen python -X utf8 -m tools.display_selection --manifest work/task.json --timeline work/fixed/timeline.json --sentence-id sentence-0007 --request work/display-request.json --candidates work/display-candidates.json --prior-origins work/origin-bindings.json --report-dir work/display-new
```

`request`保留实际句号编号、原文、checks、require_action/require_result；`display_goal`为普通介绍的`general_product`或具体特点的`visible_feature`。句长从固定时间线读取。`candidates`为1–3条`shot_id/video/source_start/source_end`，时间为源秒，来源必须在任务白名单。`prior-origins`沿用已控制的原件/代理同源时钟收据，不能按文件名猜来源。

只允许preview展示句。新目录保存候选拒绝原因、盲/语义事实、计划、时间线和可播放预览；配音、句长、字幕、BGM及组外镜头不变。`--no-render`仅验证计划。未知观察、来源变化、重播、句子身份变化或既有输出覆盖均阻断；不触碰业务表、NAS或生产队列。

## 卫品42第7句验证

原033取6.8–9.525397秒，开头清楚约0.537秒，其后为遮挡与折拢，盲观察先拒绝，未再让语义模型替其找理由。036取0–2.725397秒，主体保持展开、面层与轮廓清楚且有轻触，交集可读约2.685秒，原速选中。035画面虽清楚，关系仅为普通外观展示，不覆盖本句具体体验目标，未选中。

最终单次候选评估为3次盲观察、2次语义观察、0次额外比选；不重扫素材，不重做TTS。固定13句、直率英子1.2配音与18份派生音频/字幕文件字节一致，组外实际源帧/PTS映射一致。独立实际帧冷读支持新片段主体与面层更完整清楚；它是更贴切的体验配图，不能证明实际穿着或透气功效，连续播放节奏及整片正式验收仍未完成。真实素材、模型原答和可播放对照保存在包外私有验证目录。

开发中前两轮保留失败：一轮带文案的观察继续为折拢找理由，另一轮盲观察过度要求性能实验，误拒正常拿持。最终明确区分“主体清楚”和“功效被证明”，没有将这些失败改写为通过。
