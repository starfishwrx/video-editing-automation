## 背景与选择

活代码固定在 `packages/video-v1.5.3/`，目录后缀是历史代号；版本读 `VERSION`，部署身份看部署机器的 ACTIVE 指针和实际安装文件。干净 main 工作树是开发候选，不代表生产已更新。

## 原因与代价

避免升级时整树改名及路径断裂；代价是不能从目录名判断版本，候选、集成和安装需分别核验。
