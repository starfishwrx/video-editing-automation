# 0013 商品展示动作阶段与入出点

- 日期：2026-11-11
- 状态：已采纳为源码候选；生产部署和真实成片验收分别记录。
- 关联：[0002 AI选镜](0002-ai-selection.md)、[0006短窗放置](0006-short-window.md)、[0009冻结恢复](0009-frozen-input-recovery.md)。保留语义、变速和交付边界。

## 背景与决定

清晰静帧不能代表有效动作。固定偏向素材中后段可能删掉包装举入、转正、数量摆出和开盖揭示，剩下稳定托举。默认 `ai_editor` 识别一次展示周期：有效变化入点、首次到位、足够辨认的出点、重复或复位前的最晚可用边界。使用原素材整数微秒，绑定实际复核窗、采样帧和源身份；静态、未知和边界截断不补造动态事实。

`policy/presentation.py` 是窗口合同，与ADR0002中仅作排序的可选信息价值/主体清晰度字段分开。有阶段时，单镜、多镜和实际落稿必须保留有效入点至可辨认落点，不进入重复/复位；优先于通用头尾保护和中后段偏好。连续组按整组保护阶段，成员仍逐句核语义和源时间连续性，不要求每句重播完整动作。

旧动作描述只召回和提示少量补帧。语义响应漏掉阶段时可做专项像素观察，每个同源同窗一次，每计划最多16个源窗；不重做整库分析、TTS或原语义判断。没有有效阶段时不升级为动态阶段。

局部观察窗优先围绕旧动作描述中第一个带结果的动作，并保留前后上下文；旧时间只定位补看，不作为入出点。密集新观察可以重新定位宽采样混在一起的开盖/取包周期；不确定时保留已有事实，不从描述生成阶段。所有微秒时间是模型基于采样帧的估计，须复核最终画面，不能称为逐帧边界真值。

宽采样可能把过长稳定停留视为必要辨认时间。程序只能提出更紧凑候选窗，再用密集实帧确认；新观察保留原有效入点和首次到位点，重新确认辨认出点并记录父观察。禁止直接裁短父事实。裁切缓存绑定父阶段，改变父事实后不能沿用旧子窗许可。

阶段本身不扩大速度。无许可原速；经放置复核的完整短窗继续最高2倍，纯过程、时间敏感证明和实验分相采用各自合同。

共享池轮流汇集各介绍/钩子句的优先候选。首批已有合格展示时交放置和连续动作处理，不为极短CTA扫描整库；编辑无解最多补一轮8个展示候选，仍失败明确停止。卖点召回与证据边界不变。

单句容不下已观察的展示动作时，允许原速跨相邻介绍/钩子承接句。显式product_presentation组要求真实阶段与新的整组same_presentation观察，逐句记录实际阶段；无卖点成员不借出新卖点，卖点成员仍支持其全部点，时间敏感证明不得使用此路径。当前已经可解的动态镜头不触发此补看，新展示联合复看总预算6次、每句最多3次，先落盘再请求；旧卖点实验组条件不变。

完整选中的展示组先占用其源区间，后组不得重播同一区间或超过任务复用上限。恢复后发现旧中间方案的组间占用冲突时，保留前组、清空后组成员重新选镜，保留旧观察供审计；最终整稿去重门继续独立生效。

成片独立核验只接收待核验动作意图，不接收选镜通过结论及阶段时间。带阶段的动作事件独占审查批次，完整连续组保持整体，避免相邻无关镜头互借结果。模型核验仍可能把刚掀盖误认为完整揭示，必须如实保留与人工对照的分歧；不能据模型PASS宣称真实效果已通过。已有局部重剪路径保留邻句，动作缓存终点之后增加有界补看上下文；提示时间不自动成为真实结果出点。

明确同源重剪已经像素匹配且覆盖本句全部点时，先独立试放该候选，再试其他替代镜头；不能因另有原速静态镜头可放就丢弃有效变化。每个候选组的内层修复只看本组观察，失败才由外层切换；素材占用和refill记录从实际组装结果提取，避免名义候选与原生落稿不一致。速度许可与最终整稿证据检查保留。

## 恢复、代价与证据

阶段策略版本进入新计划恢复身份和专项缓存键。旧冻结计划保留冻结标记，连续恢复也不自动加入阶段解释；显式新任务重新选择。配音、BGM和素材观察优先复用，新阶段事实来自实际图片。

代价是有限密集抽帧、专项观察和短窗复核，以及更严格的动作窗口拒绝。程序核时间与身份，视觉语义仍需独立成片QC。源码接入不代表运行机器已部署。

验证：`test_presentation_windows.py`、`test_sentence_continuity.py`、`test_ai_editor*.py`、`test_selection_recovery.py`、完整离线回归及私有业务样例缓存重跑/示例对比。真实视频、源路径、模型响应留私有证据目录，不进入仓库。
