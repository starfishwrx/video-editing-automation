# 0004 逐句 TTS 字幕与必要校验

- 状态：已采纳（回溯补记）；基线已有相关实现，部署状态须另核验
- 原决定日期：2026-10-26。
- 补记日期：2026-11-09
- 关联／替代：关联：[独立时间线](0008-timeline-preview.md)、[冻结输入与阶段恢复](0009-frozen-input-recovery.md)。除文中说明外，未发现明确的 ADR 替代关系。

## 背景与选择

去除 ASR，字幕用原文与最终处理后的逐句 TTS 时长对齐，不宣称逐字对齐。移除多层无业务用途的哈希门槛，保留防重复调用缓存、小型 QC 元数据摘要、运输完整性与任务关联。

跨任务视觉观察按素材、源窗、规则、模型、端点和采样协议绑定；缓存命中只复用观察，不获得当前任务的成功匹配或正式交付资格。完整成功匹配报告必须绑定当前输入，匹配失败或异常使当前恢复凭证失效，不能回落旧成功报告。无绑定旧报告须显式恢复语义匹配；旧素材观察仅在相应兼容或显式导入合同允许时复用，不省略候选像素复核与独立 QC。

原始 TTS 与处理后音频分别维护缓存身份。视频窗口变化不要求重合成未变化的原始配音；归一版本、源字节或处理参数变化使对应处理缓存失效。恢复继续核对已冻结的音频身份，不因缓存存在就替换本轮绑定字节，详见 ADR 0009。

## 原因与代价

哈希不能证明画面或字幕正确，ASR 重识别不是所需时间依据；缓存复用减少重复服务调用，成功凭证的输入绑定避免把旧结果用于新任务。代价是长文本需先切成可读句段，并分别维护观察、原始音频、处理音频与任务成功凭证的失效边界。
