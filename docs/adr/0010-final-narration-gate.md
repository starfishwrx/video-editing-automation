# 0010 纸品最终配音定长与连续静音闸门

- 状态：已采纳，当前为隔离候选实现；未部署生产，未认证真实成片或听感。
- 决定日期：2026-11-09。
- 关联／替代：扩展 [0004 音频缓存与字幕](0004-subtitles-and-hashes.md)、[0009 冻结输入恢复](0009-frozen-input-recovery.md)，不替代冻结输入与五帧验收要求。

## 背景

前处理曾以 -50 dB 裁剪，再变速并编码；纸品门禁按 -40 dB 验收，处理成功不保证成片气口合格。原检测把距文件末尾40ms内结束的静音也计到文件尾，可能将其后的有声尾音算成静音。相同音频重跑会复现，整任务重试只复用失败缓存。

## 选择

纸品新TTS先从原始合成缓存做一次保调变速，跳过旧 -50 dB 预裁剪；接着按现有规则归一响度，以最终48kHz双声道PCM定位真正连续的首尾低电平采样，保留各25ms安全余量。边缘修复只执行一次，每侧最多0.5s，且输出至少保留输入60%；全静音、损坏、越过保护边界或修复后仍超限都阻断。能量保护不等同于语音完整性认证，首尾听审仍需单独完成。

选镜前将处理后的真实音频定长并预检，选择、字幕和两个写稿器消费同一最终文件。写稿前仍检查实际音频切片和时间轴，纸品五帧上限保持不变；早期预检不代替最终闸门。文件在检查后变化必须拒绝。同句多镜先聚合连续首尾静音，包含完全静音子片及时间轴间距；整句全静音仍拒绝。内部停顿与连续尾静音分别处理，结束时间只容许采样／日志舍入误差；零起点日志缺失时，仅可凭明确的结束时间和静音时长恢复证据。

恢复沿用已冻结的音频与句长，不在写稿阶段自动裁短或重新变速。保留TTS仍可按既有固定时长响度合同准备，但选镜前测量和写稿必须绑定同一处理结果；明确禁用响度时保持原件。操作者指定的普通文件音频不自动处理。旧冻结音频若仍超限，返回重排配音的阻断状态，不能冒充原选镜继续。

原始云端合成缓存保持有效；tempo/旧trim派生缓存升级为p2，以源内容、精确tempo、阈值、保留量及编码参数区分。最终PCM使用独立paper-narration-v2缓存，包含源内容与完整处理参数，锁定同目标并以独立临时文件原子发布。缓存命中验证实际文件和长度；最终资产不再重复归一或裁剪。

实测超限返回 NARRATION_GAP_EXCEEDED／timing／replan_narration；全静音或不安全修复返回 NARRATION_AUDIO_UNVERIFIED／timing；探测失败返回 NARRATION_GAP_UNVERIFIED／environment，TTS准备错误返回 NARRATION_PREPARATION_FAILED／environment。后两者要求修复环境，不引导重排文案。各类均禁止正式交付和整任务自动重试。

## 原因与代价

将音频处理放在音频定长与选镜之前，既减少后段失败的浪费，也避免音频缩短后错误复用原画面时长。PCM边缘切片不增加有损重编码，不移除中间停顿。代价是多一份派生文件与处理收据、一次本地边缘扫描；旧任务不能靠缓存升级静默换音轨，必须保留原冻结边界。
