## 背景与选择

任务已经完成素材观察、配音或选镜后，服务超时不应使已绑定的输入与成功阶段变成另一套结果。任务级重试与原始运行内的阶段恢复分别记录预算；状态文件持久保存，进程中断不清除已消耗的预算。

选镜前冻结任务输入、实际配音字节、逐句时长与素材分析身份；指定音乐也绑定文件身份。选镜服务超时／限流时，以同一原始运行的快照依次恢复预检、语义匹配和写稿，复用已完成观察与原音频，只补未完成部分。阶段恢复在启动付费选镜前持久扣除一次预算；单纯环境预检阻断可修好配置重试，不消耗该预算。

输入、配音、音乐或句长变化，必要快照缺失／损坏，或预算耗尽时明确阻断，不静默回到完整 build，也不把当前文件冒充原文件。选镜已经成功后的 BGM／写稿超时保留匹配结果，恢复对应阶段；QC／交付恢复复用既有草稿和有效证据，仍经过最终验收。任务级次数只在实际启动准备或 worker 前消耗，等待共享素材不预扣；修改输入或重复触发不重置同一记录的次数。

2026-11-09 补充（本次候选）：新队列运行MUST冻结备注原始内容、编号依据和素材复用策略；编号依据默认自然句，显式配置仍按既有支持的original_sentence/segment/split生效。显式强制重建MUST留存旧绑定后建立新快照。旧的无版本恢复MUST保留原分段编号及原复用行为，MUST NOT把新默认强加于历史输入。采用自然句编号且原始句与现有音频分段不能安全映射时MUST阻断并报告，避免错配备注；单条未命中备注按原合同保留unmatched诊断。关键词及详细边界见[AI编辑合同](../../packages/video-v1.5.3/docs/AI_EDITOR.md#备注编号与冻结恢复)。

## 原因与代价

保留已经完成的付费工作、逐句音频和证据绑定，避免重复生产及失败后切换输入。代价是恢复必须维护冻结快照、文件身份、阶段状态和持久预算；不再具备这些证据时，不能把一次新的完整制作伪装成旧运行的继续。当前次数与超时参数由运行合同维护，修改参数不自动放宽输入或正式交付边界。
