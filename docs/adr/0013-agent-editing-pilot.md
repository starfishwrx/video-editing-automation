# 0013 整单剪辑由编排 Skill 选择已有能力

日期为 2026-11-18。状态为实验分支试行。是否成为生产入口，待真实整稿的业务首审和后续多单对照决定。

## 背景

Windows 流水线能够处理从读单到原生草稿的常规工作。已有失败单留下了可用的素材观察、配音和部分选镜。整批重做这些环节花费时间，也不能解决一个镜头没有拍出卖点的问题。

## 选择和代价

编排 Skill 接受原单、指定稿或中断现场。Agent 根据当前素材决定调用整单初选、定向选镜、连续组复核或阶段恢复，用现有配音、写稿和独立 QC 做完整交付。普通展示可以比较机位建议后选择保留或成组采用。实验相位可以针对某一组分配更多可见帧。订单范围、原声身份、必需的卖点与实验过程继续在各自原有模块核验。

针对已经失败的镜头复看像素仍会产生调用；同一原单人为变更范围会影响统计。试单分别记录原始输入、手动介入次数、Agent 的修订、实际落稿和初次业务审片。只有一条成片或一次技术通过时，成稿率仍待测量。
