# 架构决策记录

这些记录回溯归拢已有选择；原决定日期无法确认时明确标注。状态描述决策而非部署，部署与验收须另核验。0001–0006、0008、0009 为已采纳的回溯记录，基线已有相关实现；0007 的实验组默认接入已随 [PR #53](https://github.com/starfishwrx/video-editing-automation/pull/53) 合入 main。各项部署须另核验。

新增、调整或废弃架构决策时，必须在同一次变更、同一 PR 中新增或更新 ADR，记录日期、状态、背景、选择、原因、代价和证据；同步本索引、受影响的 RFC／子系统文档及 `docs/working.md`，并在 PR 说明中链接对应 ADR。对话、计划和开发日志不能代替 ADR。未改变架构决策的普通修复无需新增 ADR。

新决策使用下一个连续编号。替代旧决策时保留原记录，在旧记录中标明已替代并链接新记录，新记录链接被替代项；同步本索引的状态与关联。决策已采纳、实现已合入和生产已部署分别记录，未知日期或状态明确标示，不补造历史。
