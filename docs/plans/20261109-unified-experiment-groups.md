# 三种组处理统一约束，跨文件实验进入默认 AI

本轮保留用户确认的旧卖点结论继承和完整放置短窗最高2倍速。单源分相、相邻句原速连续组、实验配对及局部变速都保留；统一的是句子归属、来源顺序、固定配音预算、完整组认证与实际输出检查。

## 默认行为

新任务的整稿用途分类增加卫品实验角色。单源分相使用语义组；历史无角色计划仍可用旧场景词作为召回提示。已有同源原速连续句处理保留。未形成认证组的吸收/反渗口播由`selection/experiment_groups.py`尝试有界配对，先核对真实商品、布置和液体状态，再观察事件及密集边界。邻接文件仅优先召回，不能证明同次实验。

默认观察走已有图片客户端，支持当前GLM/Qwen设置，不要求另配Qwen视频服务。复用`experiment_contract.validate_pair_evidence`、`compile_events`及`fit_phase_windows`，首尾/提起/结果原速，过程先≤2、最多3倍。反渗句从纸巾实际接触开始分配，不能借透气、促销或商品切换句。完整倒液无解时，仅合规定性吸收句可尝试已观察倒液尾段；省略范围写入`source_selection`。

单源还可用已定位阶段召回A/B窗口。粗阶段外扩造成的观察窗重叠不提前裁掉；实际事件细化、求解后的选择必须有序且无重播。每组最多3份不同配对，优先覆盖不同来源；预算、失败及完成观察持久保留。超时走既有语义阶段恢复；不确认或无解保持阻断，不宣称全库缺素材。

## 同一条生产与验收链

共用组约束在`policy/continuity.py`，旧`reviewed-sentence-continuity-v1`保持兼容；新实验组使用`reviewed-experiment-sentence-group-v1`。逐句配音时长决定目标区间，局部变速展开成普通恒速物理片段，在原句界切开。片段源出入点共用同一个整数切点，不补静帧、不重播，不改变原文、配音、字幕归属、BGM或组外选择。

写稿前重验实际源/目标窗口、速度、原件及配音身份；两个后端共用运行时门禁。写稿后从活动时间轴回读源区间、目标区间、速度、素材和转场。独立QC同批查看完整组，仍逐句作结论，不接收选镜器的通过理由。预览工具保持未认证，不能直接借新默认能力转正。

已有实验组定向重选时，重新复核整组关系，但只有失败句可以改画面。已接受邻句的源窗、速度和时长锁定，组外结果冻结；无法满足时明确失败，不回退到独立句匹配。旧成功计划不因新功能强迫重跑素材分析或配音。

## 验证记录

新增18项离线行为回归覆盖默认接线、跨文件与单源回退、相位保护、错误配对阻断、固定配音/组外保持、恢复复用、实际PCM音频逐句一次装配、两后端共用的运行时与草稿参数回读、完整组QC、定向修复和观察窗重叠后禁止实际重播。

独立代码审查发现的单源回退、预算来源集中、粗定位重叠过早拒绝和同源倒序问题均已补实现及回归。冻结实现`5f8073c`在全新解压包通过包级345项、编排器1457项，均零跳过；架构、CLI帮助、示例JSON和458文件库存检查通过，合包收据为`SOURCE_RELEASE_VERIFIED`。本轮不调用真实视觉/TTS，不安装运行面，不分发或回写真实业务，也未进行剪映桌面编辑验收。
