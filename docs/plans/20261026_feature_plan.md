### F01：先选音色，再处理倍速

目标流程：**保留表格原始填写值 → 拆出音色名和倍速 → 在音色表中唯一匹配并锁定音色 → 合成或复用该音色的原始配音 → 应用一次目标倍速 → 测量最终时长供选镜和字幕使用。**

- 兼容当前“真人播客女1.3倍速”等合并填写方式，不将整串作为新音色去查找。若任务已提供独立倍速，沿用显式 `voice_tempo` 优先于名称倍速、名称倍速优先于品类默认的口径；不将这些来源相乘。
- 音色查找沿用官方显示名、已知别名及speaker身份的确定性匹配；找不到或不唯一时返回明确问题和候选，不按男女或相近名称静默替换。
- 音色匹配只决定说话人；TTS后处理只改变语速。画面倍率不能进入配音倍速计算，也不能造成原始合成缓存无故失效。
- 更改倍速时从原始合成音频生成或复用对应派生文件，不对已变速的派生文件再次变速。后处理失败不能报告目标倍速已生效。
- 本次不新增字段或API；统一解析、缓存和错误处理属于后续F01实现。表格实际字段与任务适配器需一并核对，避免只修CLI入口。

### F02—F03：字幕跟随最终音频

目标流程：**原文 → 最终旁白音频 → 识别及时间对齐 → 品牌、数字和用词核对 → 语义断句 → 统一字幕轨写入 → 剪映编辑与回读验证。**

- 时间依据是最终调速和静音处理后的旁白，不根据未调速音频或字数均分推算；识别不包含BGM和素材原声的混音。
- 原文用于校对识别结果和保护词，不据原文虚构音频中不存在的内容或时间。识别缺失、明显不一致时保留待审，不能用旧的字数分摊结果冒充识别成功。
- 字幕按语义与气口组织，不在每次画面换镜时强制重起整句；同一句覆盖两个及以上镜头时保持文字与声音的连续对应。
- 生成后不再叠加用于中间处理的长条文案；原文仍保留在输入和报告中。全选移动需要在剪映内实测，并验证重开草稿后的结果。
- ASR入口的可用性、权限及识别结果粒度，和剪映可批量编辑的字幕类型，是实现前的验证项。本次不宣称已接入识别服务，也不预先指定未经验证的新供应方。

### F05—F06：画面准确优先，减少固定开场与重复

- 2倍是相近匹配质量下的偏好边界，不是整片统一使用2.0倍的目标；原速合适时继续使用原速。
- 避开前三秒是取段偏好，指**原素材时间轴的前三秒**，不是把每个已经切分的镜头再剪去三秒。短于三秒的素材不因此自动淘汰。
- 优先寻找中间段或后半段的贴切画面；唯一正确证据位于开头时可以使用，不能为满足偏好丢掉卖点、检测读数或动作结果。
- 相近匹配质量下优先较自然的速度和不同机位；稀缺卖点可保留必要复用，相关实验可跨相邻口播连续承接，避免从头重播。
- 纸品详细动作合同继续跟踪PR #15的合入和验收，本文不以介绍或包装展示替代明确性能证明，也不直接升级旧报告认证。

## 4. 实现依赖、验收与发布边界

### 后续功能验收场景

1. **音色及倍速**：合并填写、独立倍速、显式1.0倍、未知或重名音色；同一文本与音色改速后仅后处理一次，重复运行可复用正确缓存，异常不能静默换音色或当作已变速。
2. **字幕**：品牌整词、数字及较长语句；1.3倍配音；一句跨两个画面；静音处理后时间轴改变；识别失败与原文不一致；剪映全选、批量移动、保存重开。
3. **BGM**：候选充足或不足、显式指定、批次去重、同任务重试；音乐轨延后及源文件前导静音两种开头空白。
4. **选镜**：中后段有合格镜头、唯一证据在前三秒、素材总长不足三秒、2倍足够和确需更高倍速；不得以去重或速度偏好牺牲卖点完整性，最高20倍边界仍成立。
5. **生产集成**：单文案只出一条任务；参考字段为空或有值时均不伪造人工结论；已有气口、卫品及显式legacy行为保持回归覆盖。

F01先统一配音身份、倍速与最终时长，再接F02音频识别和字幕；F03必须完成剪映实测。F04和F05—F06可按各自依赖分批实施，F07—F08在任务和表格适配层验收。PR #15的源码合入、真实草稿验收及生产安装分别留证。
