# 视频时序观察与跨句视觉组

这是固定配音下的显式预览能力，默认生产与正式验收入口保持原有行为。

`orchestrator/vision/temporal_video.py` 把实际 MP4 作为 `video_url` 发送给已配置的 Qwen 兼容服务，支持请求 0.1–10 FPS。没有服务不支持时的拼图或其他模型回退。模型身份、视频身份、请求 FPS 与调用账本留在输出目录；共享客户端继续负责账号并发、期限、最多两次请求和恢复。请求 FPS 是期望采样率，不能当成服务实际看过每一帧的证明。

`ground(video, question, output, duration_us=...)` 返回本地视频时钟上的事件窗口。响应必须为整数微秒并处于实际视频范围，完整窗口包含所有事件。越界时间不会被裁成合法时间；一次结构恢复后仍失败就保留失败。该校验只解决结构和边界，不能证明时间戳准确：真实视频即使被识别，也可能得到错位时间。需要结合原始素材映射与实际 PTS 帧复核，不能把标签或 HTTP 成功变成视觉证据。

`orchestrator/selection/temporal_groups.py::replace_group` 将连续相邻句的画面作为一组，复用独立时间线与局部变速求解器。调用方提供已复核的连续源窗、每镜目标预算、独立动作/结果保护区与结果最少帧数。关键动作和结果保持原速，可压缩过程优先不超过2倍、硬上限3倍。结果区即使与动作相接，也保留自己的帧数要求。

组装器保留句子、配音、字幕、BGM和组外镜头，拒绝切开现存跨组镜头、非相邻句、源窗重播或时长不闭合。派生资产通过 `origin_asset_id` 追溯同源关系；该关系适用于同一源时钟，重置时钟或改变播放速率的派生文件必须先显式建立正确映射。实际输出仍须重新复核。替换掉的已知黑场诊断只转入历史证据，不清除音频、字幕或独立质检问题；新组继续标记待复核，不能用于 formal 时间线。

卫品42早期试验把041倒液与042按压拼接，并借用了第7句不闷热主题，违反已存在的同源完整实验和主题边界要求；此前基于画面补齐与模型匹配计数的提升结论已撤回。本轮将相关条件接入程序，9条候选未确认完整单源实验，尚未生成更优合格整片。规则、脚本入口与真实边界见[卫品同源实验](weipin-experiments.md)。

验证与收据放包外。可调用库函数复现有界观察和视觉组装，本轮候选范围和视觉组由定向验证确定，尚未实现全任务自动选组。不要将该原型描述成默认生产已自动解决时长冲突。
