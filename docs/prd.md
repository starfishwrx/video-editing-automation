# PRD — 剪映视频自动化工具包

## 1. 产品概述

### 1.1 愿景

给视频生产团队一套可版本化交付的剪映自动化能力：从素材与口播清单出发，以 GLM-5.3-Flash（`glm-5.3-flash`）理解画面并选镜，产出可打开、可审阅、可分发的剪映工程，保留选镜、时序、音画和证据合同。豆包为技能宿主名称，视觉模型以实际配置为准。

### 1.2 核心价值

- **证据驱动**：正式交付只认 `PASS`；模型超时、证据缺失、版本漂移只能是 `UNCERTIFIED` 或 `FAIL`，不允许用「大概能看」冒充成品。
- **可交接**：每个候选包自带 `ENVIRONMENT.md`、`RULES.md`、技能说明、测试与发布收据；新 agent / 新人先读路由表，不必翻聊天记录。
- **可重建**：合包命令能重建清单、ZIP、异目录解压与测试；局部修复与发版验收走同一入口，不依赖本机临时脚本。
- **运行与源码分离**：源码候选通过测试 ≠ 渲染机已升级。生产真相是 `ACTIVE_VIDEO_RUNTIME.json` 与已安装技能哈希。

### 1.3 目标用户

| 角色 | 诉求 |
|---|---|
| 运营 / 审片 | 成片口播连贯、卖点镜头对得上、字幕位置正确；能在 Mac/Windows 打开草稿审阅 |
| 渲染机运维 | 环境变量注入、队列不中断、失败有界、可回滚 |
| AI Agent | 按 `AGENTS.md` 定位模块，改完跑两套 unittest，不写死凭据与版本号 |
| 包维护者 | 按 `docs/release-process.md` 发候选包，保留历史包不可改 |

### 1.4 非目标

- 不替代剪映 GUI 做任意创意剪辑。
- 不在源码包内携带真实凭据、NAS 业务路径、生产日志或素材库。
- 不在本仓库完成「已上线」声明；部署与人工验收是独立决策。

---

## 2. 成功标准

1. **正式稿**：选镜证据覆盖口播窗口；音画时序不变量成立；草稿媒体路径在共享交付后仍可解析。
2. **预览稿**：可出图用于观察，但不得进入正式交付与「已完成」回写。
3. **回归**：`packages/video-v1.5.3/` 下包级与编排器两套 `unittest` 默认全绿；发版用 `tools.release_package build --checks full`。
4. **版本可读**：真实版本只认包内 `VERSION`（当前主线 **1.5.6**）；目录名 `video-v1.5.3` 是历史代号，不随小版本改名。
5. **视觉规则独立**：业务视觉政策版本 **1.4.1**，与工具包版本解耦。

---

## 3. 范围与边界

### 3.1 当前主线能力（VERSION = 1.5.6）

- Manifest 驱动：镜头分析 → 视觉理解 → `ai_editor` 像素复审与整稿编排 → 源窗/时序核验 → 引擎闸门 → 剪映写稿 → 独立视觉 QC v4。
- 显式 `legacy` 才使用旧 Top3、场景规则/相位打点与 QC v3；索引实验 1.5.4/1.5.5 不替代当前主线。
- 品类规则包：`global` / `weipin` / `zhipin`；配音气口全局默认无缝（`max_gap_frames=1`）。
- 草稿共享路径验收、授权后的生成版恢复、`tools.release_package` 合包验收。
- NAS 往返与跨机审阅配套工具（凭据仅环境变量）。

### 3.2 明确不做或需单独授权

- 恢复历史禁用的 JyPoll/JyRun 队列。
- 修改 `vendor/pyJianYingDraft`（除非 PR 写明来源与风险）。
- 改写 `packages/video-v1.5.2/` 及更早归档包。

---

## 4. 约束

- 语言与运行时：Python >=3.11,<3.13（以包内 `pyproject.toml` 为准）；依赖只用 **uv**（`uv sync` / `uv run`），禁止对本包 `pip install`。
- 时间口径：模块间一律整数微秒。
- 凭据：`JY_*`、`NAS_PASSWORD`、`LARK_*` 等只从进程环境读取，缺失即停。
- 文档体系对齐 grapeot / context-infrastructure 的项目脚手架：`docs/prd.md`、`docs/rfc.md`、`docs/working.md`、`docs/test.md` + 根目录 `AGENTS.md`。
